# 逐日训练器

这是可部署到 GitHub Pages 的版本。

## 使用方式

1. 新建 GitHub 仓库，例如 `training-tracker`
2. 上传本文件夹内的所有文件
3. 进入仓库 Settings → Pages
4. Source 选择 Deploy from a branch
5. Branch 选择 main / root
6. 等待 GitHub 生成网址
7. 用 iPhone Safari 或 Edge 打开网址
8. 分享 → 添加到主屏幕

## 文件说明

- `index.html`：训练器主文件
- `README.md`：说明文件

## 注意

训练记录、模板、参数会保存在当前浏览器本地。不要清理浏览器网站数据。
